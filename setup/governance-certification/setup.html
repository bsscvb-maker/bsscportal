Set up online adoption certification

This one-time setup keeps the signature records and approved document snapshots in the club’s Google Drive. You need the President’s and Secretary’s individual Google sign-in email addresses.

  1. Create the service. Sign in to the club Google account. Open Google Apps Script, choose New project and name it BSSC Governance Certification.
  2. Copy the prepared code. Replace all of Code.gs with the code below.

    Near the top, replace the two email placeholders with the officers’ own Google email addresses. Use two different accounts.

  3. Run setup once. Select setupGovernanceCertification from the function dropdown and click Run. Approve Google’s requested access. A private BSSC Governance Certifications folder will be created.
  4. Deploy. Click Deploy → New deployment → Web app. Set Execute as: Me and Who has access: Anyone. Click Deploy and copy the URL ending in /exec. Every request still verifies the signed-in officer; other users cannot access records through the service.
  5. Connect the portal. Return to Club Records → Bylaws → Adoption certification → Service setup. Paste the URL and click Save service URL, then Load certificates. The Secretary automatically uses the same address.

Use it after the adoption vote

Create the record with the correct adoption date, effective date, version and meeting-minutes reference. Review the saved PDF or Word snapshot. Each officer then signs separately from their own Google account. Once both have signed, download the Certificate PDF and retain it with the minutes.

Do not share one Google login for signing. Do not make the records folder public. This certificate records an adoption; it does not replace the required vote. No signatures are added automatically.
