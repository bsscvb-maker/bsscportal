# Sister Patch nominations deployment

The Membership link opens the public GitHub Pages shell. Big Lick is a fictional demo and does not read or write the membership workbook.

The live nomination adapter is intended for a standalone V8 Apps Script project executed as the workbook owner. Review the club's approval and access decision before enabling the form. Birthday-only verification is intended for the nomination intake and exposes the verified member's display name and eligible nominee names to a successful match. Keep reviewer scores, evidence, discipline, and approval functions behind stronger officer or reviewer authentication. Common birthdays and the reserved demo date fail closed. The shared failure limit means a burst of bad attempts can temporarily interrupt live sign-in.

1. Configure script properties `ROSTER_TAB`, `REVIEW_YEAR`, `NOMINATIONS_OPEN`, and `NOMINATIONS_CLOSE`. Use timestamps with explicit Eastern offsets. Verify the correct current roster tab and that Start Date reflects full membership. The window must span at least 14 days.
2. In the private membership workbook, create `Sister Patch Verification` with headers `Review Year`, `Roster Name`, `Attendance Cleared`, `Discipline Cleared`, `Membership Verified`, `Prior Award Cleared`. The Secretary verifies these values against official records, including documented exemptions and previous recipients, and uses Yes only for confirmed checks. Unknown checks hold the name out of the list. Use the exact first and last name from the roster and one row per person per cycle.
3. Create a private `Sister Patch Nominations` tab with headers `Key`, `Submitted At`, `Review Year`, `Nominator`, `Nominee`, `Date 1`, `Example 1`, `Verification 1`, `Date 2`, `Example 2`, `Verification 2`. Restrict workbook access through Google Drive permissions. Keep the tab private.
4. Deploy the web app, verify the response and browser cross-origin behavior from GitHub Pages, and confirm rejection of the demo birthday, duplicate dates, out-of-window intake, and ineligible nominees before setting the real deployment URL in `sister-patches/config.js`. Use controlled test data for write checks.
5. The live adapter saves nominations only. The scoring form in the demo illustrates the panel experience. Live reviewer assignment, notices and corrections, combined nomination evidence, scoring, confirmation, and presentation remain administrative steps until secured workflows are implemented. Recheck current eligibility and record the award in the roster after presentation.
